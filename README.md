# 🚀 JavaScript Journey

A collection of small projects that I've built while learning the core fundamentals of **JavaScript**.

My goal isn't just to make projects work—it's to understand how things work behind the scenes. That's why every project in this repository is built using **plain HTML, CSS, and JavaScript**, without any frameworks or libraries.

I'm documenting my learning journey one project at a time. More projects will be added as I continue learning.
